## Code

- Keep the code simple. Do not add unnecessary guards or edge-case handling.
- Comments describe the current behavior only. Do not mention past behavior or how the code worked before a change.

## Commits

- Before every commit, have Codex review the change with `codex review` and fix every P0-P2 finding. Follow the `commit` skill.
- Commit message: a one-line subject, then a body of zero or one sentence. Trailers such as `Co-Authored-By` do not count toward the body.
